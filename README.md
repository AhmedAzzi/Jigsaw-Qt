## 🎮 About The Project

**Jigsaw-Qt** is an engaging and visually pleasing jigsaw puzzle game developed using the robust Qt Framework. Put the pieces together, race against the clock, or simply relax and solve beautiful photo puzzles!

### ✨ Features
- **Classic Gameplay**: Intuitive drag-and-drop puzzle mechanics.
- **Multiple Difficulties**: Choose the number of pieces to match your skill level.
- **Customizable Images**: Play with various built-in images or potentially load your own.
- **Cross-Platform**: Built on Qt, making it easy to run on Windows, Linux, and macOS.
- **Multimedia Support**: Immersive sound effects and background animations use Qt Multimedia.

## 🛠️ Built With
- **C++17**
- **Qt** (Core, GUI, Widgets, Multimedia)

## 🚀 Getting Started

### Prerequisites
Make sure you have [Qt](https://www.qt.io/) and Qt Creator installed on your machine.
- Minimum Qt version: Qt 5.x (fully compatible with Qt 6)
- A modern C++ compiler supporting C++17

### Installation & Build
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/Jigsaw-Qt.git
   ```
2. Open the `Jigsaw-Qt.pro` file in **Qt Creator**.
3. Configure the project for your desktop kit.
4. Build and Run the project (`Ctrl+R` / `Cmd+R`).
